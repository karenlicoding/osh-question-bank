# 職業安全衛生題庫

離線優先的職業安全衛生互動題庫，包含：

網站入口：https://karenlicoding.github.io/osh-question-bank/

- 1,000 題分類題庫
- A／B 類分類勾選與各分類自訂題數的隨機練習
- 100 題全部題庫／錯題加權模擬考、百分制計分與 AI 分析提示詞
- 錯題紀錄與重點複習
- 錯題答對後自動封存，可拉回錯題區或刪除封存紀錄
- 題目本機編修、還原與備份
- A4 題庫列印

練習紀錄與自訂內容儲存於使用者瀏覽器的 `localStorage`，不會上傳至伺服器。

## 使用方式

1. 開啟網站後選擇「隨機練習」，在 A 類與 B 類分別勾選分類並指定各分類題數；可只選 A 類，也可同時混合 A、B 類。
2. 「模擬考」可從全部題庫隨機抽取 100 題，或依錯題次數加權抽取 100 題；交卷後會計分並產生可複製的 AI 分析提示詞。
3. 答錯題目會自動加入「錯題複習」並顯示累積答錯次數；在錯題練習中答對後會移至「封存區」。
4. 「封存區」可將題目拉回錯題區，或只刪除封存紀錄。
5. 「編修與備份」可修改題目、還原官方主檔，或匯出／載入包含錯題與封存區的本機備份。
6. 「A4 題庫」可瀏覽完整題庫，並使用「列印 A4」輸出。
